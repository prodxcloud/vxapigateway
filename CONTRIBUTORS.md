## Becoming a contributor

1. Pick an item from [TODO.md](TODO.md) or open an issue describing what you want to work on.
2. Fork the repo and create a branch: `feature/<short-description>` or `fix/<short-description>`.
3. Send a PR — small, focused PRs get merged faster than large ones.
4. Once merged, add yourself to the community contributors table above in the same PR or a follow-up.

## Becoming a maintainer

Maintainers are invited after a sustained pattern of high-quality contributions: thoughtful code reviews, non-trivial feature work, and reliable issue triage. If you would like to move in that direction, reach out to the current maintainers directly.

## Reporting security issues

Do **not** open a public GitHub issue for security vulnerabilities. Instead, email the primary maintainers directly (see profile links above). We aim to acknowledge reports within 72 hours and publish a fix or advisory within 14 days.

## Code of conduct

Be kind, assume good intent, and keep technical discussions technical. Harassment, discrimination, or personal attacks have no place in this project. Maintainers may remove comments, close PRs, or ban contributors for repeated violations.
